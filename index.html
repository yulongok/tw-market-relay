📈 台股資料抓取

用手機網路抓證交所／櫃買中心公開資料，存檔或推到 GitHub，給 DeskNotes 觀察股用。

1. 追蹤的股票

2. 抓資料

有填「GitHub 設定」：手機抓今日資料，歷史、財報（三率、EPS、資產負債）、月營收、上櫃股交給 GitHub Actions 抓， 抓完自動合併成一個檔。沒填 GitHub：只抓手機抓得到的（上市今日＋歷史），新代號才補歷史。
含法人籌碼、融資、集保大戶
補抓歷史每檔約 1 分鐘（證交所有流量限制），螢幕不要關。抓完一樣要存檔或推到 GitHub。

3. 交給 DeskNotes

檔名 desknotes_market_日期.json。分享時選「雲端硬碟」，存到同步到電腦 D:\desknots backup\file 的資料夾， DeskNotes 觀察股會自動讀取（或「🗄 工具2 → 📂 立即讀取雲端硬碟資料夾」）。
